# Projeto BIRL 💪

Interface web para compilar e executar código na linguagem **BIRL** (Brasil IT Rises and Late)!

## O que é BIRL?

BIRL é uma linguagem de programação humorística com sintaxe inspirada em "BIRL" memes do bodybuilding brasileiro.

## Instalação

```bash
npm install
```

## Uso

### Interface Web
```bash
npm start
```
Acesse http://localhost:3000

### CLI Direto
```bash
npx birl main.birl
```

## Sintaxe Básica

```birl
HORA DO SHOW
    CE QUER VER ESSA PORRA?("Fala, maromba! BIRL!\n")
BIRL
```

## Palavras-chave

- `HORA DO SHOW` / `BIRL` - Início e fim do programa
- `CE QUER VER ESSA PORRA?` - Imprimir (console.log)
- `OH O HOME AI PO` - Declaração de função
- `AJUDA O MALUCO TA DOENTE` - Chamada de função
- `BORA CUMPADI` - Return
- `MONSTRO`, `MONSTRAO`, `TRAPEZIO` - Tipos
- `FRANGO` - char

## Tecnologias

- [birl-js](https://www.npmjs.com/package/birl-js) - Compilador BIRL para JavaScript
- Express.js - Servidor web
- Node.js
